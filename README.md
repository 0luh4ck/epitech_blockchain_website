# Epitech Blockchain Club Website

Le site web officiel du Club Blockchain d'Epitech Bénin. Une plateforme moderne, sécurisée et performante pour la gestion des membres, des activités et de l'éducation blockchain.

## 🚀 Vue d'ensemble

Ce projet est une application web full-stack conçue pour centraliser les ressources du club, automatiser l'adhésion des membres et promouvoir l'innovation Web3 au sein d'Epitech.

- **Frontend** : React 18, Vite, Tailwind CSS v4, Framer Motion (Design Web3-inspired).
- **Backend** : Node.js, Express, TiDB Serverless (MySQL), JWT Auth.
- **Déploiement** : Vercel (Frontend), Render (Backend), TiDB Cloud (Database).

## 📂 Structure du Projet

```text
.
├── backend/            # API Express - Gestion des données et authentification
├── frontend/           # React/Vite - Interface utilisateur Web3
├── scripts/            # Scripts d'automatisation et de diagnostic
├── docs/               # Documentation détaillée (Architecture, Setup)
└── public/             # Assets partagés (Logo, images)
```
